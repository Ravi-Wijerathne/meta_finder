# MetaFinder 🔍

Extract metadata from **ANY** file type and save it to a `.txt` file!

## 🎯 Features

- Universal file support (images, audio, video, documents, archives)
- Smart file type detection
- Easy-to-use GUI interface
- Rich metadata extraction (EXIF, ID3, PDF properties, video codecs, hashes)

## 🚀 Quick Start

### Windows Users (Easiest)

1. Download [MetaFinder Portable](https://github.com/Ravi-Wijerathne/meta_finder/releases/latest/download/MetaFinder-Portable-v1.0.0.zip)
2. Extract and run `MetaFinder.exe`
3. No installation or Python required!

### From Source

```bash
# Clone and setup
git clone https://github.com/Ravi-Wijerathne/meta_finder.git
cd meta_finder
pip install -r requirements.txt

# Run (recommended)
python run_metafinder.py

# Or run directly
python main.py
```

**Note:** `run_metafinder.py` is the recommended way to launch MetaFinder as it handles environment setup.

## 📖 Usage

1. Click **Browse** to select any file
2. Click **Extract Metadata**
3. Click **Save to Text** to export results
